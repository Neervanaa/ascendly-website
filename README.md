# Ascendly - Your Smart GPS for Career Growth

Ascendly is an AI-powered platform for career and education consulting that helps professionals transition from their current job to their dream career through efficient learning routes and strategic career planning.

![Ascendly Website](https://github.com/user-attachments/assets/db9dcc72-99e5-4403-a6c7-b31320e8a093)

## Features

- **Personalized Career Roadmap**: Customized paths tailored to your skills, experience, and career goals
- **AI-Powered Guidance**: Advanced AI identifies the most efficient learning routes
- **Curated Learning Resources**: Hand-picked courses, certifications, and resources
- **Progress Tracking**: Detailed analytics and milestone tracking
- **Industry Insights**: Real-time market trends and in-demand skills
- **Career Consulting**: Connect with expert consultants for personalized advice

## Tech Stack

- **React 19.2**: Modern React with the latest features
- **Vite**: Fast build tool and dev server
- **CSS3**: Custom styling with responsive design
- **ESLint**: Code quality and consistency

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Neervanaa/ascendly-website.git

# Navigate to the project directory
cd ascendly-website

# Install dependencies
npm install
```

### Development

```bash
# Start the development server
npm run dev
```

The application will be available at `http://localhost:5173`

### Build

```bash
# Build for production
npm run build
```

The production-ready files will be in the `dist` directory.

### Preview Production Build

```bash
# Preview the production build locally
npm run preview
```

## Key Components

- **Header**: Navigation bar with links and CTA button
- **Hero**: Main landing section with Smart GPS messaging and visual illustration
- **Features**: Six key features showcasing platform capabilities
- **HowItWorks**: Four-step process explaining how Ascendly works
- **CallToAction**: Conversion section encouraging users to get started
- **Footer**: Company information and links

## Customization

The website uses a consistent color scheme based on purple gradients (`#667eea` to `#764ba2`). To customize:

1. Update colors in component CSS files
2. Modify content in component JSX files
3. Add new sections by creating new components
